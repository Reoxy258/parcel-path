# 晴空幸存者 · Sunlit Survivors

一款十分钟的怪潮生存游戏。一个竞技场，四面八方涌来的花海怪潮；你只管走位与冲刺，飞信自动瞄准射击。击败小怪掉落晶石，集满经验条就升级三选一——多重飞信、穿透、环绕叶片、荆棘光环……活到 10 分钟，就是胜利。

## 玩法

单屏竞技场，一局 10 分钟，死亡即结算、秒开新局。每局的出怪时刻表固定（同「印记」种子下完全一致），强化选项与场地障碍由印记随机生成——每局都是一次新的构筑。

- **怪潮导演**：飞虫 → 疾跑小蛛 → 蹦蹦芽 → 喷籽蘑菇按时刻表陆续加入；2 分半起出现金环精英（5 倍血量、掉 10 晶石）；3、6、9 分钟各有一位花园守卫（环形弹幕 + 扇形种子交替，掉 50 晶石）。全程无空场，敌人总量上限 70。
- **晶石与升级**：击杀掉落晶石，走近自动吸附（磁力可升级到全场）。集满经验条暂停出三选一：8 项被动（攻击 / 射速 / 多重 / 穿透 / 移速 / 体力 / 磁力 / 护甲，各 5 级）+ 2 项专属武器——**环绕叶片**（公转飞叶碰撞伤害）与**荆棘光环**（周身周期范围伤害），最多 4 级。经验溢出会连续升级。
- **战场利用**：灰石挡人挡弹（绕圈走位的掩体）；木箱打碎掉 2 晶石；金色荆棘周期升起，对怪潮同样有效——引着它们踩上去。
- **难度缩放**：敌人生命随时间 ×(1+t/150)、攻击 ×(1+t/320) 增长；护甲沿用收益递减的减伤公式，叠甲无法把伤害压穿。
- **死亡与纪录**：倒下即结算本局（时间 / 等级 / 击败 / 晶石 / 承伤），最佳纪录（最久坚守、守住次数、最高等级）存在本浏览器。

| 操作 | 方式 |
| --- | --- |
| 移动 | WASD / 方向键；手机按住屏幕方向按钮 |
| 射击 | 全自动：瞄准最近可见敌人 |
| 冲刺 | 空格 / 冲刺按钮，短暂无敌，有冷却 |
| 暂停 | P / Esc / 暂停按钮；窗口失焦时自动暂停 |

## 本地运行

需要 Node.js 22 或更新版本，不需要安装依赖。

```sh
npm run dev
npm test
npm run build
```

打开 `http://127.0.0.1:4173`。ES Modules 需要 HTTP 服务，不能直接双击页面运行。构建后的 `dist/` 可以部署到静态 HTTPS 托管；相对资源路径支持 GitHub Pages 仓库子路径。

`main` 更新后，GitHub Actions 自动测试、构建并发布到现有 Pages 地址。

## 结构

| 文件 | 内容 |
| --- | --- |
| `index.html` / `src/adventure.css` / `src/survival.css` | 响应式游戏界面（升级对话框、计时与经验条 HUD） |
| `src/survival.js` | 生存核心：出怪导演、敌人行为、晶石经验、升级三选一、胜负判定 |
| `src/survival-scene.js` | 竞技场渲染：组装场景绘制、精英金环、环绕叶片、荆棘光环 |
| `src/survival-ui.js` | 输入、音效、升级弹窗、结算面板、最佳纪录 |
| `src/scene.js` | Canvas 绘制函数库（以撒精灵主角、四张怪物图集、几何障碍、晶石） |
| `src/world.js` | 种子随机（mulberry32）与敌人 / 区元数据定义 |
| `src/adventure.js` / `src/adventure-ui.js` | 保留的旧版房间冒险模拟与界面（测试仍在验证） |
| `assets/sprites/` | 用户提供的以撒与四张怪物原图 |
| `tests/survival.test.js` | 生存模式规则与 90 秒自动战斗验证 |
| `tests/adventure.test.js` / `tests/dungeon.test.js` | 旧版冒险规则与生成确定性验证 |
| `puzzle.html` / `src/app.js` | 保留的旧版机关解谜入口与实现 |

游戏运行时不需要账号、后端、外部字体或远程图片。音效使用 Web Audio 合成，默认关闭。怪物素材来源和使用帧范围见 [素材说明](docs/ASSETS.md)。
