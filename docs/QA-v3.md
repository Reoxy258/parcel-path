## 审查后修复

1. 荆棘致死与最后敌人被击败同帧时，死亡状态可能被守卫奖励覆盖。清房前和清房处理内均校验 playing；加入回归测试。
2. 清房时清除敌方残余弹幕，防止强化选择后立即受到旧弹幕伤害；加入回归测试。
3. 清房后仍允许手动射击，自动瞄准可见木箱，箱内金币可收集；加入回归测试。
4. 第三次双叶飞信原来无收益，现支持从三发升至四发；加入回归测试。
5. 小屏开始卡片压缩，避免按钮被画面裁切；手机展示攻防属性。
6. 横屏手机／平板等宽屏触控设备也显示移动方向键。
