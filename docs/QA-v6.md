# QA 记录 · v4.0.0（生存流改造）

对应提交：本轮 `feat: 生存流改造——竞技场怪潮、晶石升级三选一、十分钟一局`。前置基线：v3.2.1（以撒精灵主角，见 QA-v5.md），35 项测试全绿。

## 改造动机与方案

用户判断：「这个游戏没有前途，作为休闲小游戏不好玩」。诊断结论：

1. 战斗半自动——自动瞄准砍掉了射击爽感的一半（但在生存流里自动瞄准反而是正确设计）；
2. 局体量错配——30 房 6 层是 20–40 分钟的 Roguelike 骨架，休闲游戏要 3–10 分钟一局；
3. 每局一样——4 商品 + 6 强化没有构筑分叉；
4. 空房间稀释战斗密度。

选定方向 A（用户确认）：改造成吸血鬼幸存者式生存流——单屏竞技场怪潮 + 击杀掉晶石 + 升级三选一 + 10 分钟一局 + 死亡秒重开。最大化复用：以撒主角精灵、四张怪物贴图与行为相位机、粒子、音效、几何障碍绘制、三选一对话框 UI；旧冒险模式代码与测试全部保留。

## 新玩法实现

| 模块 | 内容 |
| --- | --- |
| `src/survival.js` | 模拟核心：波次导演（9 段时刻表 + 精英 + 3/6/9 分钟守卫）、敌人相位机（时间缩放版）、晶石磁吸与拾取、升级三选一（8 被动 + 环绕叶片 + 荆棘光环 + 兜底治疗）、600 秒胜利 / 体力归零死亡 |
| `src/survival-scene.js` | 竞技场渲染：地板随时间换六区配色、精英金环、光环/叶片绘制、低血量边缘警示 |
| `src/survival-ui.js` | 计时 / 经验条 / 等级 / 击败 HUD、升级对话框（复用 reward-dialog）、死亡与胜利结算、最佳纪录 localStorage |
| `index.html` | 入口换 survival-ui.js，侧栏改为「本局等级 / 击败 / 最佳纪录」，操作只剩移动 + 冲刺 |

- **构筑分叉**（针对性修复「每局一样」）：环绕叶片（1+级数片公转飞叶，碰撞伤害 9+攻击×0.55）与荆棘光环（半径 42+16×级，每 0.55 秒 tick）是全新武器机制；被动各 5 级上限；经验溢出连续升级；强化池耗尽后兜底「花间小憩」（恢复 45%）。
- **无空场**（修复战斗密度）：出怪间隔从 1.6s 逐步压到 0.42s，总量上限 70；敌人生命 ×(1+t/150)、攻击 ×(1+t/320) 缩放；软性挤开防止叠成一摞。
- **短局重开**（修复体量错配）：10 分钟胜利；死亡即结算（时间 / 等级 / 击败 / 晶石 / 承伤），一键再守一局。
- **战场利用**：木箱打碎掉 2 晶石；金色荆棘对地面怪潮同样造成 24/s 伤害——可以把怪潮引过去；灰石仍是挡弹掩体。
