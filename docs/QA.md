# 验证与审查记录

日期：2026-10-21。平台：Windows、Node.js 24.14.1、应用内 Chromium 浏览器。

## 分工

- 主 agent：玩法选择、规则与 UI 实现、自动求解、回归测试、浏览器操作、修复与交付。
- DeepSeek Harness：独立静态检查规则、关卡、求解器和存储层。其环境的 PowerShell 启动失败，因此不将它的静态结论称为动态测试通过。
- OpenCode：第一轮工具审查和第二轮附带源码的短审查均达到超时限制，未交付完整结论，其过程说明不作为审查通过依据。UI 审查由补充的独立 agent 和主 agent 的实际浏览器测试完成。
- 独立 UI 审查 agent：只读检查提示、行走、弹窗竞态和响应式布局。

## 已修复问题

1. **非法方向名污染坐标**：`toString` 等继承属性会被误当作方向。改为只接受 `DIRECTIONS` 的自有属性，加入回归断言。
2. **损坏存档选中未解锁关卡**：存储层现在也会约束选中关卡，UI 与存储层均进行解锁检查。
3. **提示高亮残留**：取消提示时同步移除棋盘上的旧高亮，打开、关闭帮助弹窗后不会继续显示过期提示。
4. **延时通关弹窗可能与其他弹窗叠加**：打开新弹窗时取消待显示的通关弹窗，并保证同时只有一个原生对话框。
5. 制作期间发现两张初版地图不可解，调整障碍布局后才纳入最终关卡；最终 12 张地图全部可解。
